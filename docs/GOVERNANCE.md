# Governance and Decision-Making

**Status:** Initial governance direction.

## 1. Project leadership

marmelOS is currently maintained and directed by Atharva Lohar.

The maintainer is responsible for project direction, release decisions, accepting or declining contributions, and maintaining the project's official documentation, subject to applicable law and contributor agreements.

## 2. Decision-making

Major project decisions should be documented rather than existing only in informal conversation.

Technical decisions should explain the context, options considered, chosen approach, and consequences. Use Architecture Decision Records (ADRs) for decisions that materially affect system structure.

## 3. Contributions

Contributors may propose changes and provide patches. Acceptance is not guaranteed. Contribution ownership and publication permissions should be agreed individually in writing.

## 4. Releases

Only releases published through the project's designated official channels should be represented as official marmelOS releases.

Release naming, signing, support policy, end-of-life policy, and security-response procedures will be documented before the first public release.

## 5. Changes to project policy

Policy changes will be dated and documented. The project will distinguish between terms applying to future releases and terms already granted for existing releases. No retroactive change will be implied without a clear legal basis and appropriate notice.
